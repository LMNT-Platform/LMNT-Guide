# LMNT Developer Guide

Static GitHub Pages site for the LMNT Platform developer guide.

## GitHub Pages

Publish from the `main` branch root:

1. Open repository Settings.
2. Go to Pages.
3. Set source to `Deploy from a branch`.
4. Select `main` and `/ (root)`.

The site entrypoint is `index.html`, which loads `manual.html` after the LMNT intro animation.
